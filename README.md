## 23. Guides to Key Workflow Operations

### 1. 3D & CG Asset Pipelines (KitBash3D/Blender → Game Engines)

1. **Asset Retrieval:** Download environments via **KitBash3D Cargo** or **ArtStation Marketplace**.

2. **Prep & UV Mapping:** Open assets in **Blender** to check scale, PBR materials, and clean UV unwrap seams.

3. **Texture Painting:** Export to **Adobe Substance 3D Painter** for custom wear, rust, and micro-details.

4. **Export:** Send finalized models as `.FBX` or `.GLTF/GLB` with embedded materials directly into Unreal Engine or Unity.

### 2. Video & Motion Graphics Pipeline (Adobe & Open-Source)

1. **Rough Cut:** Assemble raw video footage inside **Premiere Pro** or **DaVinci Resolve**.

2. **Visual Effects:** Dynamic-link scenes into **After Effects** (or DaVinci Fusion) for visual effects, keying, and lower thirds.

3. **Color Grading:** Perform final LUT adjustments and color passes in **DaVinci Resolve** or **Lightroom/Camera RAW**.

4. **Audio Mastering:** Clean noise floor and balance dialogue in **Adobe Audition** or **Audacity** before final export.

### 3. AI Safety & LLM Red Teaming Evaluation

1. **Test Suite Definition:** Define prompt injection evaluation vectors using **Promptfoo** or **garak**.

2. **Automated Scanning:** Execute automated red-teaming benchmarks against target APIs using **PyRIT** or **LLM Guard**.

3. **Guardrail Defense:** Intercept malicious inputs at runtime using **Lakera Guard** or **Meta Llama Guard 3**.

4. **Metric Logging:** Monitor context recall, faithfulness, and latency metrics in **Arize Phoenix** or **RAGAS**.
